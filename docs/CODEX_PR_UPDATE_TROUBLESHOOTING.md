# Codex PR 업데이트 불가 시 대응 가이드

## 현재 증상

Codex에서 기존 PR을 업데이트하려고 할 때 다음 메시지가 발생할 수 있다.

> Codex에서는 현재 외부에서 업데이트된 PR 업데이트를 지원하지 않습니다. 새로운 PR을 생성해 주세요.

이 메시지는 기존 PR 브랜치가 GitHub, 다른 작업자, 또는 다른 자동화에서 이미 변경되어 Codex가 동일 PR에 안전하게 추가 push/update를 수행할 수 없을 때 발생한다.

## 운영 판단

이 경우 기존 PR을 억지로 업데이트하지 말고 **새 PR을 생성**한다.

권장 운영 흐름은 다음과 같다.

1. 기존 PR은 리뷰/비교용으로 유지한다.
2. Codex 작업 결과는 새 커밋으로 정리한다.
3. 새 PR을 생성해 기존 PR 링크 또는 제목을 PR 본문에 기록한다.
4. GitHub에서 새 PR 기준으로 CI를 다시 실행한다.
5. 새 PR이 정상 동작하면 기존 PR은 close 처리한다.

## 로컬/실행 환경 점검

브랜치 업데이트가 안 될 때는 먼저 다음 명령으로 원인을 확인한다.

```bash
python -m scripts.check_branch_update_ready
```

점검 결과에서 확인할 항목은 다음과 같다.

- `remotes: (none)`이면 현재 체크아웃에 GitHub 원격 저장소가 없다.
- `upstream: (none)`이면 현재 브랜치가 원격 브랜치를 추적하지 않는다.
- `dirty_files`가 0보다 크면 커밋되지 않은 변경사항이 있다.

## 이번 케이스 결론

현재 요청의 핵심은 기존 PR 업데이트가 아니라 **새 PR 생성**이다. 따라서 이후 수정사항은 새 커밋으로 남기고 새 PR로 제출한다.
